# 垃圾分类识别助手

这是一个面向校园场景的纯前端垃圾分类项目。用户可以输入垃圾名称，或上传图片后补充物品名称，系统会返回分类类别、投放建议、分类原因和注意事项。

项目采用 HTML、CSS、JavaScript 和 JSON 实现，不需要安装后端或数据库。页面可直接打开，也可以通过任意静态服务器运行。

## 已完成功能

- 108 条校园常见垃圾数据，覆盖可回收物、有害垃圾、厨余垃圾、其他垃圾
- 名称完全匹配、关键词或别名匹配、包含匹配、简单模糊匹配
- 完整结果卡片：垃圾名称、类别、投放建议、分类原因、注意事项、相似查询
- 图片上传、格式与大小校验、本地预览、文件名辅助判断
- 10 个热门垃圾快捷查询
- 宿舍、食堂、快递站、教室四类校园场景入口
- 四类垃圾科普与易混淆提醒
- 最近 8 次查询记录，本地保存，可一键清空
- 响应式布局、键盘焦点、语义化标签和减少动画适配
- 断网可用，不上传用户选择的图片

## 运行方式

### 方式一 直接打开

双击 `index.html` 即可使用。知识库已同步到 `garbage-data.js`，因此不受浏览器本地文件读取限制。

### 方式二 本地服务器

在项目文件夹中执行：

```bash
python3 -m http.server 8080
```

然后打开：

```text
http://localhost:8080
```

## 查询逻辑

查询按以下顺序评分：

1. 垃圾名称完全匹配
2. 关键词或常见别名完全匹配
3. 名称或关键词包含匹配
4. 编辑距离不超过 1 至 2 个字符的简单模糊匹配
5. 无结果时显示友好提示和推荐样例

例如输入“饮料瓶”可以匹配“饮料塑料瓶”，输入“餐巾纸”可以匹配“纸巾”。

## 修改或增加数据

`garbage.json` 是交付知识库。每条记录包含：

```json
{
  "id": 1,
  "name": "矿泉水瓶",
  "category": "可回收物",
  "keywords": ["塑料瓶", "空水瓶"],
  "suggestion": "倒空残液，简单清洗并压扁后投放到可回收物桶。",
  "reason": "瓶身通常由可回收塑料制成，清洁后可以再生利用。",
  "note": "瓶盖可拧回瓶身；若沾有大量油污，应先清洁。",
  "scene": "宿舍"
}
```

编辑 `garbage.json` 后，如果电脑已安装 Node.js，执行：

```bash
npm run data:sync
```

该命令会检查条目数量、必填字段、类别、场景、重复编号和重复名称，再更新 `garbage-data.js`。不要手工修改 `garbage-data.js`。

## 图片功能说明

当前版本完成任务书要求的基础稳定流程：图片上传、格式限制、本地预览、名称辅助输入和分类结果展示。系统会尝试从文件名中寻找物品名称，例如 `矿泉水瓶.jpg`，但不会声称已经接入或训练图像识别模型。

如需自动识别，可在后续版本接入 TensorFlow.js、Teachable Machine 或合规的图像识别接口，再将识别标签交给现有知识库匹配。

## 建议演示流程

1. 搜索“矿泉水瓶”，说明名称完全匹配和结果卡片。
2. 搜索“餐巾纸”，说明别名匹配和纸巾易混淆原因。
3. 点击热门查询中的“废电池”“苹果皮”。
4. 上传一张命名为“奶茶杯.jpg”的图片，确认文件名提示并查看投放建议。
5. 切换校园场景和分类科普，最后展示查询历史。

## 数据口径与参考

本项目采用任务书中的四分类口径，并参考公开政府分类指引整理常见物品。不同城市的低值可回收物渠道和具体细目可能不同，页面已提醒用户以当地最新规定为准。

- [北京市垃圾分类知识指南](https://www.bjfsh.gov.cn/zhxw/fsdt/202405/t20240508_40075659_fs.shtml)
- [上海市生活垃圾分类投放指引 2024版](https://www.shanghai.gov.cn/gwk/search/content/40b9feaa-53db-472f-8a6b-2c3cf0465def)
- [江门市城市生活垃圾分类指导目录](https://www.jiangmen.gov.cn/bmpd/jmscsglhzhzfj/zwgk/tzgg/content/post_2506402.html)

## 注意事项

- 任务书源文件保留在项目文件夹中，没有修改。
- 图片仅在浏览器本地预览，不会上传到服务器。
- 查询历史仅保存在当前浏览器的 LocalStorage 中。
- 垃圾分类细则存在城市差异，校园实际投放时应以当地和学校要求为准。
